ℹ️ ¿Cómo se determina el ganador?

El código ganador se obtiene cruzando el resultado del sorteo con la Lotería de Medellín. Se toman los 3 últimos dígitos del premio mayor más el primer número de la serie. El código que coincida con esa combinación es el ganador.

Ejemplo: Premio mayor 1234 · Serie 2 → código ganador: 2342

Cerrar evento y empezar nuevo

Guarda todo lo de esta dinámica en el historial y deja las tablas activas en cero

⚠️ Esta acción:
• Guarda todas las compras, códigos vendidos, el ganador y la config actual en el historial (no se pierde nada).
• Vacía la tabla de compras y libera todos los códigos vendidos (el pool de códigos sigue igual, solo queda disponible de nuevo).
• Oculta el ganador publicado y desactiva el banner y cualquier promoción vigente.
• No se puede deshacer desde el panel: una vez cerrado, el evento nuevo empieza desde cero.

Configurar la nueva dinámica (opcional)

Si la llenas, se aplica automáticamente al cerrar el evento actual. Si dejas "Cantidad de números" vacío, se conserva el pool actual tal cual.

Si la dejas vacía, se usa la fecha de hoy.
⚠️ Esto regenera por completo el pool de números (0000...N-1). Solo hazlo aquí, justo al cerrar el evento. Puedes escribirlo con o sin puntos (1000 o 1.000).
